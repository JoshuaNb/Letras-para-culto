# Letras para culto 1.5.0 — Compatibilidade com Windows antigos

O programa mantém o nome **Worship Studio**. A versão 1.5 inclui um instalador universal x64 que seleciona automaticamente a edição adequada ao Windows, mantendo os recursos de biblioteca, projeção independente, letras animadas, quatro temas, Holyrics, controle Android e atualização pelo aplicativo.

## Novidades

- **Windows 7 SP1, 8, 8.1, 10 e 11 x64:** duas publicações do mesmo aplicativo. Windows 10 build 19045/22H2 ou superior e Windows 11 usam .NET 10; os demais usam o runtime legado .NET 6.0.36 incluído.
- **Instalação offline:** os dois runtimes, LibVLC, FFmpeg e APK acompanham o instalador. Não exige SDK nem download do .NET no computador de operação.
- **Renderização legado:** Skia por software, sem o ANGLE moderno incompatível com Windows antigos. As animações, fontes, cores e controles de projeção continuam disponíveis. A edição atual mantém GPU e fallback.
- **MP4 nos sistemas antigos:** FFmpeg recompilado do fonte para Windows 7/MSVCRT, com MPEG-4, AAC, entrada PNG e composição do vídeo de fundo. A edição moderna conserva seu FFmpeg.
- **Rede e atualização:** leitura completa de corpos HTTP compatível com .NET 6, preservando cancelamento, autenticação e tratamento de conexão truncada. O atualizador legado usa TLS 1.2 explicitamente.
- **Atualização preservada:** mesmo AppId, biblioteca e preferências. O instalador remove somente binários pertencentes à outra edição para evitar misturar runtimes.

## Instalar

1. Baixe e execute **WorshipStudio-Setup-1.5.0.exe**. O instalador escolhe a edição; não é necessário escolher ou baixar um segundo pacote.
2. No Windows 7, é obrigatório **SP1** e **KB3063858 ou atualização equivalente com AddDllDirectory**. Se faltar essa API, o instalador informa o componente e encerra antes de modificar a instalação. Não atualiza o Windows automaticamente.
3. A biblioteca, as cenas e as preferências são mantidas. Quem usa 1.3 ou 1.4 pode buscar esta versão em **Atualizações**; quem usa 1.0–1.2 deve instalar manualmente uma vez.
4. O APK 1.4 continua compatível com o PC 1.5. O APK 1.5 está incluído para novas instalações e transferência offline em **Conexões → Baixar APK para Android**.

**Windows de 32 bits e Windows 7 sem SP1 não estão incluídos.** A edição legado renderiza por software, portanto o desempenho depende da CPU, da resolução e dos fundos utilizados. A operação permanece offline; consultas ao GitHub exigem internet, TLS 1.2 e certificados válidos.

## Verificação e limites

Instalação e atualização aprovadas em três cenários isolados: 1.4 → 1.5 atual, 1.4 → 1.5 legado e troca de legado para atual. Os dois runtimes abriram usando as dependências da própria instalação; biblioteca e preferências foram preservadas. A instalação original do operador permaneceu inalterada.

**583 verificações aprovadas, zero falhas finais:** 138 de núcleo, 108 de renderização e 26 da interface em cada runtime, 32 Java e sete de dependências/exportação do FFmpeg legado. Os resultados, auditoria das dependências e ensaios dos dois caminhos do instalador estão registrados em [VERIFICACAO.md](../../VERIFICACAO.md).

**A execução do aplicativo em máquinas Windows 7, 8 e 10 não foi observada nesta sessão.** Os ensaios locais usam Windows 11, incluindo o runtime legado e o caminho legado do instalador. A preparação dos binários para sistemas antigos e a auditoria de imports não substituem essa validação física ou virtual. A edição não restaura suporte oficial da Microsoft ou do Avalonia aos sistemas cujo ciclo de suporte terminou. Permanecem também os limites já documentados de teste físico do celular, biblioteca real do Holyrics, dois monitores e áudio da igreja.
