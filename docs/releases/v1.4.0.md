# Letras para culto 1.4.0 — Controle Android e biblioteca do Holyrics

O programa de PC e seu instalador mantêm o nome **Worship Studio**. Esta versão conserva a biblioteca, as cenas, os quatro temas, a galeria de animações e a atualização pelo aplicativo.

## O que mudou desde a 1.3

- **APK nativo Android:** Letras para culto · Controle, em português brasileiro, para Android 8.0 ou superior. Funciona na rede local, sem conta, nuvem ou conexão com a internet durante a operação.
- **APK disponível também offline:** o instalador de PC inclui o arquivo Android; **Conexões → Baixar APK para Android…** salva uma cópia para transferir ao celular. O download oficial permanece disponível na Release.
- **Pareamento por código:** informe o IPv4/porta exibidos no PC e o código de seis dígitos. O código vale por dez minutos; tentativas são limitadas por IP e globalmente. Desligar e iniciar o controle remoto gera novas credenciais.
- **Comandos de operação:** anterior, próxima, tela preta, ocultar letra, pulso de efeito e escolha direta de estrofes. O celular acompanha a letra e o estado atuais; a projeção continua no PC se ele desconectar.
- **Conexão anterior preservada:** o APK também aceita o link completo com token do controle web. O aplicativo lembra o endereço do PC; código e token permanecem somente em memória e não são incluídos em backups ou logs.
- **Baixar letras do Holyrics:** nova janela para consultar a biblioteca instalada, filtrar por título/artista, marcar músicas e baixar apenas as letras selecionadas, com progresso e cancelamento. O lote é adicionado à biblioteca local somente ao terminar.
- **Uso offline após importar:** as letras e suas estrofes ficam salvas no Worship Studio. A consulta utiliza o API Server local do Holyrics, com token de leitura; não baixa áudio ou MP3 nem usa um catálogo da internet.

## Conectar o celular

1. Instale `WorshipStudio-Setup-1.4.0.exe` no PC e `LetrasParaCulto-Controle-1.4.0.apk` no Android.
2. Conecte os dispositivos à mesma rede local. No PC, abra **Conexões** e inicie o controle remoto.
3. No APK, informe endereço/porta e o código exibidos no PC e toque em **Conectar**. Também é possível colar o link completo com token.
4. Prepare uma apresentação no PC e use os comandos do celular. O APK controla a apresentação atual; a biblioteca e a projeção continuam no computador.

O pareamento por código exige PC 1.4.0. O link completo com token permanece compatível com o controle remoto anterior. Se o código expirar antes de conectar, desligue e inicie novamente o controle remoto no PC. Isso revoga também os acessos anteriores.

## Baixar as letras do Holyrics

1. Mantenha o Holyrics aberto no PC ou na rede local, ative seu **API Server** e configure um token com leitura de músicas/letras.
2. Em **Conexões → Holyrics**, abra o download de letras. Informe o endereço e token do API Server; no mesmo PC, o endereço pode ser `http://127.0.0.1:8091`, conforme a porta configurada.
3. Clique em **Buscar músicas**, use a busca e marque os louvores. **Selecionar visíveis** marca os resultados filtrados.
4. Clique em **Baixar letras selecionadas** e aguarde o lote terminar. Cancelar a operação não adiciona parcialmente essa seleção à biblioteca.

O download corresponde às **letras da biblioteca instalada e autorizada pelo operador**. Depois de importar, essas letras podem ser projetadas offline sem manter o Holyrics aberto.

## Verificação e limites

**320 verificações aprovadas, zero falhas:**

| Suíte | Aprovações |
| --- | ---: |
| Núcleo e serviços, incluindo 18 casos de pareamento e 19 de Holyrics | 130 |
| Renderização e animações | 108 |
| Interface principal real em Avalonia Headless/Skia | 26 |
| Janela Holyrics real em Avalonia Headless/Skia | 7 |
| Parser de conexão Android em Java | 32 |
| Integração HTTP real do cliente Java incluído no APK com a operação do PC | 17 |

As provas cobrem expiração e limites de tentativas, seleção e cancelamento, falhas da API, endereço local, porta e formato de credenciais. A integração HTTP utiliza o cliente Java exato do APK contra `RemoteServer`, `MainWindow`, `ProjectionWindow` e `StageSurface` de produção no backend headless. Ela conferiu comandos, estado, pulso, autenticação e revogação. O APK final foi compilado, assinado e alinhado; o manifesto da Release contém seu SHA-256.

Essa integração HTTP **não executa a Activity Android nem simula toques**. O emulador tentado sem hypervisor ficou indisponível; nenhuma configuração do sistema foi alterada. A Activity e a operação em celular físico não foram observadas. Os testes Holyrics usam respostas controladas da API oficial, sem comprovar uma instalação real específica do programa. O relatório `VERIFICACAO.md` distingue também a validação do instalador das suítes automatizadas.

Permanecem os limites anteriores: dois monitores físicos, equipamento da igreja, áudio não nulo, benchmark de FPS/latência, importação de modelos 3D, edição livre de keyframes, BPM e sincronização de sílabas. As animações interpretam imagens estáticas de referência.
